## Why SQL Cockpit?

SQL Server work is usually scattered across SSMS windows, scripts, spreadsheets and tribal knowledge. **SQL Cockpit brings it together** in a shared, modern operations product built for teams. It is offered as a cloud service or a heavily customised self-hosted deployment, and scales from small operational databases to enterprise data platforms.

SQL Cockpit doesn't have to replace SSMS. It complements it, and cuts out the manual context-switching.

## Frequently asked questions

<details>
<summary><b>Does SQL Cockpit replace SSMS?</b></summary>
<br>
Not necessarily. It complements SSMS and reduces reliance on manual SSMS workflows by bringing management, search, synchronisation, migration and monitoring into a shared interface.
</details>

<details>
<summary><b>Which databases are supported?</b></summary>
<br>
SQL Cockpit is built around Microsoft SQL Server workflows, covering management, migration, synchronisation, object search and operational visibility.
</details>

<details>
<summary><b>Is it suitable for enterprise databases?</b></summary>
<br>
Yes. It's designed for everything from small operational databases to enterprise-scale SQL Server data platforms and high-volume migrations.
</details>

<details>
<summary><b>Can it help with SQL Server migrations?</b></summary>
<br>
Yes. Teams use it to inspect database objects, plan table movement, track progress, validate changes and reduce manual operational work.
